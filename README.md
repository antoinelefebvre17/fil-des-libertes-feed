# Le Fil des libertés — flux public

Fichier des fiches lu par l'app « Le Fil des libertés » : `feed.json`, publié sur GitHub Pages.

Il ne contient que des titres, liens, dates et résumés, avec la source de chaque élément. Jamais le texte intégral des sources protégées.

Le fichier est régénéré chaque semaine par le pipeline de l'app (dépôt privé).
